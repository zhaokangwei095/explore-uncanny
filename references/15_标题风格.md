# 15 · 标题风格（两种流派 + 硬规则）

> 什么时候用：Phase 2 定故事线之后、写 `meta.cover.title` 之前。
> 标题决定**点不点进来**，比封面图更早生效。

---

## 一、先选流派（二选一，别混）

### 流派 A · 定名式（4–8 字，纯名词）

**参考**：《深山禁寺》= 4 字

```
【地形/场域】+【性质词】
深山 + 禁寺
哑口 + 隧道
会喘的 + 矿洞（8 字，偏长但可用）
无灯 + 窟
```

**适用**：题材有强视觉辨识度（巨像/蛇/佛/巨构），画面本身就能勾人。

**优点**：短、好记、有留白、截图不糊
**风险**：太平就会无人点——**必须有一个"不对劲"的字**
> 禁寺的"**禁**"、骨坡的"**骨**"、哑角垭的"**哑**"——不是"废弃矿洞"（平），是"**会喘**的矿洞"（怪）

**禁忌**：
- ❌ 超过 8 字（封面排不下、手机小图糊）
- ❌ 纯写实无怪味：「山中寺庙」「废弃工厂」
- ❌ 堆形容词：「神秘诡异的深山古寺」

---

### 流派 B · 钩子式（12–24 字，一句完整悬念）

**参考**：《父亲失踪三年后，我在雪山里收到了他的信号》= 22 字

**四段式结构**（这是它能成立的原因）：

```
【关系/身份】+【时间】+【地点】+【一个反常的事实】
父亲失踪三年后 + 我 + 在雪山里 + 收到了他的信号
```

再拆一个例子：
```
我被辞退三个月后 + 我 + 在旧厂考勤表上 + 看见了自己的名字
（关系：被辞退的我｜时间：三个月后｜地点：旧厂｜反常：名字还在）
```

**要点**：
- **必含一个"不可能"**：失踪三年的人发来信号 / 被辞退的人还在打卡
- **第一人称"我"**（代入感），或第三人称"他"（旁观感）——**全篇统一**
- **不剧透结局**：只说"收到了信号"，不说"他是外星人"
- **逗号断一次**（超过 15 字必须断，否则一口气读不完）

**禁忌**：
- ❌ 超过 24 字（信息过载，读者扫不完）
- ❌ 用"震惊/细思极恐/吓哭/千万别"这类标题党
- ❌ 剧透反转（等于把底牌摊在封面）
- ❌ 感叹号/问号连用（破坏"纪实冷静"的调性）

---

## 二、两种流派的共同铁律

1. **不做标题党**——数据最好的两个样本，标题都极克制。这个赛道靠"可信"吃饭，标题党会反向毁掉可信度。
2. **不剧透结局**——钩子只给"疑问"，不给"答案"。
3. **"不对劲"的信息必须有一个**，但只给一个。给两个就变说明文。
4. **标签 2–4 个，精准不蹭**：
   - 好：`#aigc #诡异 #怪诞 #徒步 #佛像`
   - 坏：`#热门 #上热门 #推荐 #爆款`
5. **和封面标题字数匹配**：封面大标题建议 ≤ 8 字；流派 B 的长标题放到**正文首行/简介**，封面取其中**最勾人的 4–6 字**做短标题。

> 例：标题《父亲失踪三年后，我在雪山里收到了他的信号》
> → 封面短标题可取「**雪山的信号**」（5 字），长标题做正文开场。

## 三、10 个可直接套的句式（流派 B）

| 句式 | 例 |
|---|---|
| `我{做了什么}，{反常结果}` | 我进了那条隧道，出来时少了一天 |
| `{X}失踪{N}年后，{反常事件}` | 父亲失踪三年后，他的旧手机开机了 |
| `自从{事件}，{持续的怪事}` | 自从那场雨，村口的钟每天早响一分钟 |
| `没人知道{事实}，除了{某人/物}` | 没人知道他去了哪，除了他桌上那本日记 |
| `{地点}有个规矩：{怪规矩}` | 那口井有个规矩：天黑后不能照镜子 |
| `我在{地点}，找到了{不该有的东西}` | 我在废弃气象站，找到了十年的值班记录 |
| `{X}之后，{某物}开始{反常}` | 工厂停产之后，考勤表每天还在更新 |
| `{数字}年前的事，今天又发生了` | 四十年前的事，昨晚又发生了一次 |
| `{某人}回来时，{某处不对}` | 他回来那天，家里所有的钟都慢了七分钟 |
| `如果{条件}，千万别{动作}` | 如果听见有人叫你名字，千万别应 |

## 四、自检（发布前）

- [ ] 标题属于 A（≤8字）或 B（12–24字）之一，没有混搭
- [ ] A 流派有一个"不对劲"的字；B 流派有一个"不可能"的事实
- [ ] 没有剧透结局
- [ ] 没有标题党词（震惊/细思极恐/千万别…）
- [ ] 标签 2–4 个，精准
- [ ] 封面短标题 ≤ 8 字，且与长标题不重复啰嗦
- [ ] 把标题单独发给一个没看过内容的人，他会不会想问"然后呢"？**不会 → 重写**
