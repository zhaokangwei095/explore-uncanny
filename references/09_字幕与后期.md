# 09 · 字幕与后期

> ⚠️ **第一铁律：中文绝不让生图模型画。** 任何模型画中文都会出伪汉字/乱码，直接毁掉整组图。

---

## 正确流程

```
生干净底图（无任何文字）
  → 后期叠字幕（剪映 / Photoshop / Figma / PPT 都行）
  → 导出 1080×1920
```

---

> 版式参照图：`examples/`（本 skill 自己生成的成品）

## 字幕版式规范（对齐"纪录片旁白"感）

| 项 | 值 |
|---|---|
| 字体 | **默认 Noto Sans SC + Black 字重**（粗、有冲击力，网感）；`fonts/` 里若放了「得意黑 SmileySans / 阿里巴巴普惠体 / 抖音美好体」则优先用（最网感） |
| 字号 | **画面宽度 × 0.062**（1080 宽 ≈ 67px，比早期 1/28 明显更大） |
| 行数 | 2–3 行，**均衡换行**（各行宽度接近），行距 1.55 |
| 颜色 | `#FFFFFF`，不透明度 92% |
| 底框 | **圆角矩形，只包住文字块**（宽度=最长行+内边距），半透明黑 alpha≈120，圆角≈0.3 字号；**绝不是整幅长条** |
| 位置 | 画面下方（默认中心在 80% 高处），水平居中；可 `--y` 调 |
| 标点 | 句末句号；不用感叹号/问号/emoji/标题；**标点不出现在行首**（自动禁则处理） |

### 用脚本烧字幕（必须）

```bash
python scripts/burn_subtitles.py <项目目录>
# 可选：--font-size-ratio 0.07  --y 0.82  --alpha 140  --font /path/CJK.ttc
```
输出 `out/subtitled/`，交付这目录里的图。字体自动探测（Win 雅黑 / mac 苹方 / Linux Noto CJK），找不到会报错而不是静默跳过。

## 文案语感（第一人称 · 陈述句 · 短句 · 每句一个信息点）

> 例：
> 「我只能继续往前。／{空间}另一边，／有一道很奇怪的入口。」

写作要点：
- 主语用"我"，像在给朋友复述
- 越平静越好——**画面越瘆人，旁白越要冷**
- 不用形容词堆砌，用事实（"台阶不见了"而不是"太可怕了"）
- 每帧 1–2 句，全组 25–40 句

---

## 旁白结构建议（和七拍对齐）

| 拍 | 旁白作用 | 示例语气 |
|---|---|---|
| Ⅰ | 交代"我为什么在这" | 「我一个人来{地点}。」 |
| Ⅱ | 一个轻微疑问 | 「门是开着的。里面没人。」 |
| Ⅲ–Ⅳ | 冷静描述诡异 | 「我回头，台阶不在原来的位置了。」 |
| Ⅴ | 承认看不懂 | 「过了很久，才看清那是什么。」 |
| Ⅵ | 松口气 | 「我终于回到了正常的{场景}。」 |
| Ⅶ | 一句反转 | 「照片重新出现了。{多出来的东西}。」 |

## 生成字幕文案的小技巧（可选）

如果不想手写，可以给 LLM 一句提示：

> "以下是一组 25 帧探险图文的画面描述（附后）。请写 25 条第一人称旁白，每条 1–2 句、陈述句、句号收尾、不用感叹号，语气冷静克制，像给朋友复述。按帧顺序输出，不要加解释。"

---

## 交付前字幕检查

- [ ] 没有一帧的字是模型画的（全部后期）
- [ ] 字号统一、行距统一、位置不压人脸
- [ ] 全组旁白语气一致（都冷）
- [ ] 没有感叹号/问号/emoji/标题
- [ ] 最后一帧的旁白就是那个"增量"，且点到为止
