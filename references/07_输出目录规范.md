# 07 · 输出目录规范

每做一组，输出到独立目录，避免和别的组混。

```
./explore-uncanny/<选题slug>/
├── 01_选题卡.md            # Phase 1
├── 02_故事线.md            # Phase 2
├── 03_分镜表.md            # Phase 3（人读）
├── scenes.json             # Phase 3（机器读，gen_pack.mjs 的输入）
├── 04_提示词全套.md        # Phase 4（gen_pack.mjs 生成）
├── prompts.json            # Phase 4（机器读）
├── render_commands.txt     # Phase 4（可直接执行）
├── README.md               # Phase 5（交付说明：先跑哪张、怎么锁人、怎么叠字幕）
└── out/                    # 出图落这里
    ├── 00_定妆照.png
    ├── 01_xxx.png
    └── ...
```

- `<选题slug>`：选题的关键词，英文或拼音，如 `deepsea-rig`、`weather-station`
- 用户在某个已存在的项目目录里时，就近创建子目录，不要覆盖别人的文件
- `scenes.json` 是**唯一事实来源**：`04_提示词全套.md` 和 `prompts.json` 都由它生成，不要手改生成物

## scenes.json 结构（gen_pack.mjs 依赖）

```json
{
  "meta": {
    "title": "深海钻井平台",
    "slug": "deepsea-rig",
    "frame_count": 21,
    "style_key": "STYLE",
    "hero_frame": 7
  },
  "scenes": [
    {
      "id": "01",
      "beat": "Ⅰ 现实锚点",
      "one_liner": "直升机降落在平台上，风很大",
      "rules": [],
      "camera": "C3",
      "fig_scale": 50,
      "light": "L1",
      "style_variant": "STYLE_DAY",
      "compo_variant": "default",
      "lens": "eye",
      "scene_en": "Scene: ...",
      "fig_anchor_en": "He is ... ",
      "title": "登台",
      "subtitle_zh": "我跟着补给直升机上了平台。"
    }
  ]
}
```

字段说明：
- `style_variant`：`STYLE` | `STYLE_DAY` | `STYLE_WARD`
- `compo_variant`：`default` | `down` | `ward`
- `lens`：`up` | `down` | `eye` | `screen`
- `fig_scale`：仅作参考记录，**不进提示词**（脚本会忽略它拼装，只用于人工核对）
- `fig_anchor_en`：**尺寸比喻在前、位置在后**，脚本直接用它替换 `__A__`
- `scene_en`：以 `Scene:` 开头

## 命名约定

- 帧号两位补零：`01`–`25`
- 图片文件名与帧号一致：`out/01_登台.png`
- 顺序即叙事顺序，**不要按拍序号重排**（否则后期配音会乱）
