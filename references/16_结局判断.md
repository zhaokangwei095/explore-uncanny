# 16 · 结局：由你判断怎么收

> **不要套模板、不要按套路选。** 读完你写的故事，**自己判断**这一组该在哪里停、停成什么样。
> 这里给的不是"菜单"，是**判断的依据**。

---

## 一、先想清楚一件事

**这组的"恐怖"到底是什么形状的？**

- 如果是**"多了一个东西"**——那是一种具体的、可以指认的不对劲 → 收在那样东西上
- 如果是**"某个事实说不通"**——那是一种逻辑上的裂缝 → 收在那个裂缝上，**不要解释**
- 如果是**"某个动作即将发生"**——那是一种悬着的势 → 收在那个动作之前

你不是在三种格式里选一个，你是在**判断：我讲到最后，最该停在什么上面**。

---

## 二、判断的四个问题（自己回答）

```
1. 我这个故事，最刺人的那个点是什么？
   （不是"最恐怖"，是"最让你自己不舒服"的那一下）

2. 那个刺点，是"一个东西"、是"一个说不通的数"、还是"一个还没发生的动作"？

3. 读者读完，我更希望他做什么？
   - 复述给别人听 → 停在一个清楚的东西上
   - 自己回去重看、想不明白 → 停在一个不解释的矛盾上
   - 追问下一集 → 停在动作上

4. 我有没有在结尾多说了什么？
   （几乎必然有。删掉它。）
```

---

## 三、不同判断，收法自然不同

**如果你判断：这组的刺点是"多出来的一样东西"**
→ 收在那东西上，白描，不评论。
```
工位上插着我的工牌。茶还是热的。
```

**如果你判断：这组的刺点是"一个算不通的事实"**
→ 收在那个事实的**矛盾**上，给数字/物证，**不解释为什么**。
```
门卫说：这卡一直有人用。每天刷两次，早上七点，晚上十一点。
```

**如果你判断：这组的刺点是"某种还没结束的东西"**
→ 收在一个**即将发生的动作**上，切在它发生前。
```
凌晨三点，厂区的灯又亮了。我抬手，敲了敲门。
```

> 这三种不是"选项"，是**三种不同的判断结果**。你判断成什么，就收成什么。也可能你的故事是第四种——那就收成第四种。**别为了套模板去扭曲判断。**

---

## 四、不管怎么收，五条纪律（这几条必须守）

1. **只留一个刺点。** 两个以上，读者会开始推理，恐惧感被解题欲取代。
2. **物证要具体。** "七点和十一点" ＞ "经常有人用" ＞ "感觉不对"。能用数字/物件的地方，别用形容词。
3. **不解释。** 写完就停。**不写"这到底怎么回事""也许""原来是"**。
4. **不总结情绪。** 不写"我后背发凉""我陷入恐惧"。让物证说话。
5. **停在最锋利的地方，不是最完整的地方。** 完整感是敌人。

---

## 五、最容易写坏的五种（自查时逐条对）

| 症状 | 为什么坏 | 怎么改 |
|---|---|---|
| 「这到底是怎么回事？」 | 反问=把读者当傻子，等于承认你没想好 | 删掉，让物证自己说话 |
| 「也许他只是……但也可能……」 | 列可能性不是留白，是不敢下判断 | 删掉整段 |
| 「有东西在看着我」 | 没有物证的空话，读者无感 | 换成一个具体的东西/数字 |
| 「原来人最怕的是自己」 | 强行升华，变成鸡汤 | 删掉，回到画面 |
| 一个故事给三个疑点 | 变成推理题 | 只留最刺的那个 |

---

## 六、收尾最后一刀（每次都要做）

写完结局，做这件事：

> **把最后一句单独拿出来读。**
> 问自己：**这句话删掉，故事会不会更好？**
> 如果删掉之后只是"少了点信息"，但恐怖感没减 → **删掉**。

大多数 AI 写的结局，**最后一句都是多余的**。它想"说圆满"，而好故事是在没说完的地方停。

---

## 七、和"换场景"的关系（这条不变）

三幕七拍的 **Ⅶ 反噬必须换场景**（野外 → 室内）。这是**节的规则**。
**换场景之后在哪停、停成什么样——你自己判断。** 这是**点的规则**。

两者叠加，不是替代。

---

## 八、交付时要说明你的判断

在 `02_故事线.md` 的结尾段，写一句：
```
结局判断：这组的刺点是"一个算不通的考勤记录"，所以收在"工号已注销但仍在打卡"的矛盾上，不解释。
```
> 写出来，是为了逼自己真的判断过，而不是随手收尾。
