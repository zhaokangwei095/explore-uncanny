# 13 · 新闻选题与去标识化（用真实事件做灵感，但不暴露真实地址）

> 适用：选题来自新闻/热搜/真实事件时**必读**。
> 一句话原则：**留情绪，不留坐标。**

---

## 一、为什么必须脱敏（三条真实风险）

1. **隐私与名誉**：真实地点 + 虚构的恐怖情节 = 暗示某地"闹鬼/有脏事"，可能构成对具体村镇、单位、当事人的影射。国内已有因"虚构故事影射真实地点"引发的投诉与删帖。
2. **平台风险**：涉真实地名 + 灵异/灾难/案件，容易被判"不实信息""引人不适"而限流。
3. **二次伤害**：真实事故的当事人、家属会刷到。哪怕你写的是"虚构"，他们看到的是自己家。

**结论**：新闻只能当"情绪与结构的原料"，不能当"事实的坐标"。

---

## 二、三步转化法

### 第 1 步：提取"事件骨架"（只留抽象结构）

从新闻里只拿这些：
- **发生了什么类型的事**（失联 / 塌方 / 废弃设施 / 异常信号 / 集体失踪）
- **人的处境**（一个人去找人 / 一群人不肯说 / 一个人回来了但变了）
- **情绪的真相**（等待、愧疚、执念、被隐瞒）

**不要**记录：具体是哪一年、哪个县、哪座山、多少人、谁说的。

### 第 2 步：剥离"识别信息"（逐项替换）

| 识别信息 | 必须处理 | 处理方式 |
|---|---|---|
| 地名（省/市/县/村/山/河） | **必改** | 换成"南方某省山区""西北某条无名沟"；或虚构地名（见 §三） |
| 机构（单位/公司/学校/医院） | **必改** | 换成"某勘测队""当地一家小厂""县里的卫生院" |
| 人名 | **必改** | 只留姓或代号；主角默认"我"，配角用"老周""队长" |
| 精确时间 | **必改** | 改成"三年前""那年冬天"；不要写具体日期 |
| 特征数字 | 建议改 | 楼层、人数、吨位、海拔、里程——这些是"指纹"，容易被反查 |
| 特有地貌/建筑 | **必改** | 把"XX天坑""XX隧道"改成通用描述（"一口竖井""一条半塌的引水洞"） |
| 方言/口头禅 | 建议改 | 会暴露地域 |
| 新闻原文措辞 | **禁用** | 不引用"警方通报""据当地村民称"这类原文句式 |

### 第 3 步：重铸"虚构外壳"（加一层不可能对应的东西）

**关键动作**：加入一个**现实中不存在的超自然/科幻层**，让改写后的故事**不可能与任何真实事件一一对应**。

- 例：真实新闻是"施工队在山里失联" → 你写成"他们在山里找到一座不该存在的祠堂，钟声每天准时响一次"
- 这层"不可能"是**法律与伦理上的隔离带**：它把作品从"影射真实事件"变成"借用母题的虚构创作"。

---

## 三、地名改写模板（可直接套）

| 真实类型 | 安全写法 |
|---|---|
| 具体县/村 | 「南方某省的山里」「一个不通车的村子」 |
| 具体山/峰 | 「一座没名字的山脊」「当地人不愿意提的那道梁」 |
| 具体隧道/矿/洞 | 「一条停用的引水洞」「一口废矿井」 |
| 具体建筑 | 「镇子边上那栋三层小楼」「半山腰的旧观测站」 |
| 具体水域 | 「山坳里那口塘」「水库最深处」 |

**虚构地名配方**（要"像真的但查不到"）：
`地形词 + 方位/形态` → 「黑石坳」「断颈梁」「落雁沟」「哑口」。
**不要**用真实存在的著名地名组合（如"太行""哀牢""秦岭"这种强指向的，能不用就不用）。

---

## 四、内容红线（无论怎么改都不能碰）

- ❌ 不写真实受害者的姓名、外貌、家庭
- ❌ 不暗示某个真实机构/单位"闹鬼""掩盖真相"
- ❌ 不编造真实人物的罪行
- ❌ 灾难/事故/医疗类要更保守：**不要出现"某年某地死了多少人"这种可对照的细节**
- ❌ 不出现"根据真实事件改编"这种声明（会反向指认）
- ✅ 可以写："本故事纯属虚构，与任何真实地点、人物无关"（安全，且平台喜欢）

---

## 五、去标识化自检（发布前必过）

1. **反查测试**：把文案给一个不知道原新闻的人看，他能不能搜到原事件？**能 → 没脱敏。**
2. **地名测试**：把所有地名替换成"某地"后，故事是否依然成立？不成立说明地名承载了太多识别信息。
3. **家属测试**：如果当事人的家属看到，会不会觉得在说自己家？会 → 再抽象一层。
4. **对照测试**：把真实新闻和你写的文案并排放，除了"类型相似"，还有没有**可一一对应**的细节？有 → 删。

---

## 六、落盘字段（写进 scenes.json 的 meta）

```json
"meta": {
  "topic_source": {
    "type": "news",
    "based_on": "公开报道中的同类事件（已合并、已抽象）",
    "anonymized": ["地名", "机构", "人名", "时间", "特征数字"],
    "fictional_layer": "加入不存在的祠堂与钟声，确保无法与真实事件对应",
    "disclaimer": "本故事纯属虚构，与任何真实地点、人物无关"
  }
}
```

`type` 只能是 `"original"`（原创）或 `"news"`（新闻改编）。
**选了 `news` 就必须填 `anonymized`（非空数组）和 `fictional_layer`**，否则 `validate.mjs` 会报错。

---

## 七、给 agent 的操作口径

用户说"这个是从新闻看来的"「根据某个真实事件」时：

1. **先声明规则**：一句"我会保留事件的情绪结构，但把地点、单位、人名、时间全部虚化"，让用户知道你会改。
2. **不要反问真实地名**：用户主动说了真实地点，你也**不要写进产物**（连选题卡里都不写具体名，写"某省山区"）。
3. **产出 `topic_source` 字段** + 一句免责声明。
4. 交付时报告里带一句：`已去标识化：地名/机构/人名/时间`。
