# 10 · 实测结论（为什么这么写；要改提示词前必读）

> 这些结论来自对原样本的 A/B 实测（多轮，本地生图模型，n=1~6），不是拍脑袋。
> 如果你要改提示词措辞，先看这里，避免踩已经踩过的坑。

---

## A. 已确证（≥2 次复现或有外部样本，可以依赖）

| 结论 | 证据 |
|---|---|
| `found footage / hiking vlog / smartphone` 会让模型画出 **REC 时间码水印**，负向 `no camera UI` 挡不住 | 标签流版本直接出现 `REC 2023-10-27 14:32:05` |
| 正文里写 `no 3D render / no CGI` 会**反噬**，画面更像 CG | 加了否定句的版本是全部里最像 3D 渲染的 |
| `Naga` 一词会被画成"竖立的眼镜蛇" | 6/8 张；改成"蛇身绕柱两圈、头在柱顶、闭嘴侧脸"才对 |
| "嘴就是门" 要写死几何，且**嘴不张开**才不长獠牙 | 2/2 + 外部样本；`lips parted` 会长獠牙 |
| 巨构**被画框切断**是硬锚点，不写就出完整雕像、恐怖感归零 | 8/8 |
| **人物占比由机位决定，不由形容词决定**（平视 28–39% / 陡俯视 7–13%） | 三轮一致 |
| 前景遮挡 + "画面不居中"是**破对称海报感**的唯一可靠开关 | 3/3 |

## B. 已实测（小样本，可信但别当铁律）

- **L3 手电：6/6 无硬边舞台追光**。副作用 1/6：`entering from the viewer's position` 会把**实体手电筒**画进画面，不需要就删该短语。
- **DAY 变体：3 张 / 2 场景通过**，S02 正殿一次即中，说明 DAY 可迁移。偏翠、人物偏大（靠拉远机位）。
- **COMPO_DOWN：命中率约 2/4**，是概率不是开关。S13 四张里 1 张完全达成（人物 7%）、1 张半成、2 张退回"正前方立脸"。**必须 `count≥4` 挑。**
- **`no ceiling and no vault`** 能帮顶部被裁断，但不保证。

## C. 已撤回（曾经的结论，后来被证伪，别再引用）

- ❌ **"尺寸比喻单用 → 人物 16%"**：round-3 用几乎同一句复测是 **28–30%**，16% 是单次运气。正确口径：**尺寸句把 39% 拉到 28–30%，拉不到 12–13%**。
- ❌ **"人物占比写百分比"**：0/8 生效。
- ❌ **"只写位置句（inside the lowest quarter）"**：反而把人物放大到 **37–39%**。

## D. 未实测（别写成结论）

- S04 保留共享 COMPO 的判断、`cartoon/anime` 类负向词、WARD 屏内照片、`no ceiling` 对其它帧的效果
- 输出尺寸：实测仅 768×1376，亚像素细节（尘埃颗粒）无法判定

## E. 适配你的模型（重要）

### E1. 生图模型 = Gemini 系（Nano Banana / gemini-3-pro-image / gemini-*-flash-image）

**好消息：本 skill 的全部词级结论就是在这个家族上跑出来的，可以直接照用，不用打折。**
包括这些"反常识"的结论都成立：
- `found footage / vlog / smartphone` 会长出 REC 时间码 → 别写
- 正文写 `no 3D render / no CGI` 会**反噬** → 别写，靠正向颗粒/低动态
- `Naga` 会被画成竖立眼镜蛇 → 用"蛇身绕柱、头在柱顶"的描述
- 百分比控不住人物大小 → 用机位 + 尺寸比喻
- 高方差帧（俯视深井 / 定价帧）→ 必须 `count=4` 挑图

→ **跑法**：`aspectRatio=9:16`（Gemini 支持宽高比），普通帧 `count=1`，关键帧 `count=4`。

### E2. ⚠️ 对话模型不是 Gemini 时，最容易踩的坑

如果**写提示词的对话模型**（比如豆包 / DeepSeek / GLM）与**生图的 Gemini** 不同族，风险是：
> 对话模型喜欢"帮你润色"——把 `desaturated, matte low-contrast` 改成 `cinematic moody atmosphere`，把简短硬件描述改成文学描写。**改一个词，风格就崩。**

因此对写提示词的模型有一条硬规矩（已写进 SKILL.md）：
- **prompt_en 整段照抄 `gen_pack` 生成的结果，一个字都不许改。**
- 绝对禁止"翻译、润色、缩写、加形容词、改语序"。
- 要调也只调 `scenes.json` 里的变量字段（scene_en / fig_anchor_en / 机位 / 光），改完重跑 `gen_pack`，不去直接编辑成品 prompt。

### E3. 其它生图模型（万一换）

- **`gpt-image-2`**：更"听话"、负向更有效；"负向反噬"那条**可能不成立**，值得复验。防 CG 的正向锚点仍保留。注意它不收 `aspectRatio`，用 `size=1152x2048`（正好 9:16）。
- **Flux / SDXL**：负向词有效，但单条别超 ~600 token（SDXL 77 token 会截断），用逗号标签版（见 `04_提示词拼装.md` 末尾）。
- **其它**：先跑 1 张定价帧试水，再决定要不要调。

## F. 一句话方法论

> **风格靠固定前缀，人物尺度靠机位，怪诞靠 R 规则组合，真实靠"湿+噪点+哑光"，文字靠后期。**
> 任何一条想省掉，都会在图上被看见。
