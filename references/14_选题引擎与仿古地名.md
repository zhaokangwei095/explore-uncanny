# 14 · 选题引擎：互联网取材 + 仿古地名

> 什么时候用：用户说「帮我想几个选题」「随便来个题材」「最近有什么好素材」，或说「从网上找点灵感」。
> 铁律：**取材只取"事件类型 + 情绪"，地名一律仿古虚构。**

---

## 一、为什么要仿古地名（而不是直接改）

- **真实地名**（不管今名古名）→ 可能被反查到具体地方 → 影射风险 + 平台限流
- **纯虚构现代名**（"白石村"）→ 太"编"，不出味道
- **仿古虚构** → 既有文化质感，又**查不到对应今址**，最安全

> 判断标准：把地名丢进搜索引擎，**搜不到对应的具体地点**才算合格。

---

## 二、仿古地名构词法（四类公式）

从真实古地名词汇里提炼**构词部件**，重新组合。组合出来的名字"像古地名"，但不指向任何真实地点。

### 部件库

| 类型 | 部件 | 例 |
|---|---|---|
| **地形词** | 岭 / 梁 / 坳 / 峪 / 峡 / 塞 / 关 / 隘 / 坡 / 渡 / 津 / 汊 / 窝 / 陀 / 塬 | 黑石**坳**、断颈**梁** |
| **水体词** | 溪 / 潭 / 涧 / 泉 / 沱 / 汀 / 浦 / 濑 | 哑泉**涧**、落雁**潭** |
| **建筑词** | 驿 / 铺 / 寨 / 堡 / 屯 / 台 / 观 / 祠 / 庵 / 关厢 | 哑角**驿**、石喉**关** |
| **修饰词** | 黑 / 哑 / 断 / 枯 / 残 / 幽 / 阴 / 骨 / 尸 / 铁 / 灰 / 空 / 死 / 寒 | **哑**口、**骨**坡 |
| **数字/方位** | 头 / 尾 / 腰 / 底 / 上 / 下 / 十八 / 九 | **十八**盘、**腰**栈 |

### 四种配方

**配方 A · 单字修饰 + 地形词**（最稳，2–4 字）
```
黑 + 石 + 坳  → 黑石坳
断 + 颈 + 梁  → 断颈梁
哑 + 口      → 哑口
骨 + 坡      → 骨坡
```

**配方 B · 动作/物象 + 地形词**（有画面感）
```
落雁 + 滩  → 落雁滩
倒 + 影 + 潭 → 倒影潭
无 + 灯 + 窟 → 无灯窟
```

**配方 C · 数字 + 地形词**（有古驿道感）
```
十八 + 盘 → 十八盘
九 + 曲 + 涧 → 九曲涧
三 + 岔 + 口 → 三岔口
```

**配方 D · 古官职/军事词 + 地形词**（有边塞感）
```
哨 + 鹿 + 关 → 哨鹿关
戍 + 边 + 堡 → 戍边堡
兵 + 马 + 驿 → 兵马驿
```

### 命名黑名单（这些别用）

- 仍在使用的大地名：秦岭、太行、哀牢、昆仑、巫山、武陵、敦煌……
- 著名风景区：九寨沟、张家界、神农架、哀牢山……
- 真实存在的古关隘（易查）：剑门关、娘子关、嘉峪关、函谷关……
- 任何你能在脑内对应到具体省份的组合

## 三、取材流程（三步）

### 第 1 步 · 搜（只搜"事件类型"，不记录地点）

搜索方向示例（不是固定 query，按需变化）：
- 「某地 废弃 矿洞 传闻」
- 「深山 失踪 多年 未解」
- 「老厂区 停产 之后」
- 「连续 多年 同一类 怪事」

**只抄下**：
- 事件类型（事故/失踪/废弃/重复怪事/集体沉默）
- 人的处境（找人的人 / 不肯说的当地人 / 回来但变了的人）
- 核心情绪（等待、愧疚、执念、被隐瞒、恐惧被记住）

**绝对不抄**：地名、机构名、人名、日期、人数、伤亡数。

### 第 2 步 · 抽象（写成卡片）

```
事件类型：山里的作业队失联，只回来一个
人的处境：回来的人说不清，也没人敢问
核心情绪：被留下的人，一直在等一个解释
```

### 第 3 步 · 落成选题（套配方取名 + 给怪诞层）

```
选题名：断颈梁（配方 A）
场域：南方某省山区（不上具体省）
怪诞源：回来的那个人，带回了不属于他的口音
一句核心恐怖：山没有留住他们，是山里的"某样东西"记住他们了
结尾增量：录音里多了一句他用别人的嗓音说的话
```

## 四、产出格式（写进 `01_选题卡.md`）

```markdown
# 选题卡 · 断颈梁

- **选题来源**：互联网取材（已抽象，无具体事件对应）
- **取材类型**：单人返回类失联事件（通用母题）
- **抽出的情绪**：等待、被隐瞒
- **地名**：断颈梁（仿古虚构，配方 A；已确认查无此地）
- **场域**：南方某省山区（**不写具体省/县**）
- **子类型**：A 民俗怪诞
- **一句核心恐怖**：山里的东西记住了他们
- **结尾增量**：录音里多出一句用别人嗓音说的话
- **目标帧数**：15–21
```

并在 `scenes.json` 的 `meta.topic_source` 写：
```json
{
  "type": "news",
  "based_on": "互联网取材的通用母题（已抽象，无具体事件对应）",
  "anonymized": ["地名", "机构", "人名", "时间", "人数", "特征数字"],
  "fictional_layer": "会记住并复述人声的山体",
  "place_name_style": "invented_archaic",
  "place_name_verified_not_real": true,
  "disclaimer": "本故事纯属虚构，与任何真实地点、人物无关"
}
```

## 五、一次给多个选题（搭配选题）

用户说「给我几个选题」时，给 **5 个**，覆盖不同场域，便于挑：

| 场域 | 选题名（示例） | 一句钩子 |
|---|---|---|
| 地下 | 无灯窟 | 矿灯照到的最后一面墙上，刻着还没发生的事 |
| 水下 | 落雁潭 | 水底的村子，比岸上的完整 |
| 垂直 | 十八盘 | 这条古道每走一遍，就少一个台阶 |
| 废墟 | 哑角驿 | 废弃驿站每天凌晨准时亮灯，没人住 |
| 异境 | 骨坡 | 山坡的石头按呼吸的节奏起伏 |

> 每个都必须：**仿古虚构名 + 查无此地 + 不指具体省份 + 带一个怪诞层**。
