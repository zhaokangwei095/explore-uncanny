# 16 · 结局怎么收（三种收法 + 留白纪律）

> 什么时候用：Phase 2 定故事线、写结尾增量时。
> 核心：**结局不是"讲清楚"，是"停在对的地方"。** 有时给答案，有时只给疑点——取决于你想留什么后劲。

---

## 一、三种收法（先选，别混）

### 收法 1 · 增量式（给答案，但答案是"多了一样东西"）
**特征**：读者能明确知道"多了什么"，但不知道"为什么"。
**适用**：最稳，适合大多数题材、适合想涨粉的账号。

```
照片里多了一个穿我外套的人。
录音里多了一段我的呼吸声。
B超上多了一个穿冲锋衣的侧影。
```
**力度**：★★★★☆（明确的不对劲）
**风险**：低。读者能复述，容易传播。

---

### 收法 2 · 疑点式（**只给疑点，不解释**）★ 你最想要的那种
**特征**：给一个**确凿的、可验证的**物证或事实，但**完全不给解释**。故事在"为什么"之前停住。
**适用**：想要"看完会重看一遍""评论区吵起来"的作品。

```
主角逃出来，回到城市。最后一张图：他在网上搜自己当年失踪的新闻，
搜索结果 0 条。（他明明上过新闻）
```
```
他把照片发给朋友，朋友回：这是什么？照片里只有一面墙。
```
```
医院记录显示：他住院那天，体表温度一直是 27 度。
```
```
他回到家，桌上摆着三副碗筷。他家只有两个人。
```

**疑点式的三条铁律**：
1. **只给一个疑点**——给两个就变成"线索题"，读者会开始推理，恐怖感反而消散
2. **疑点必须"可验证但无法解释"**：是照片、是记录、是数字、是物证——**不是含糊的感觉**
3. **绝不补一句解释**：写完就停。不要加"这到底是怎么回事""也许……"——**这是最容易被 AI 写坏的地方**

**力度**：★★★★★（后劲最大）
**风险**：中。写不好会"闷"——因为没兑现。**必须确保疑点本身足够刺人。**

---

### 收法 3 · 悬置式（收在一个动作/一句话，不做任何收尾）
**特征**：故事在最高点直接切断，不留画面兜底。
**适用**：短平快、单条爆款、或者系列集的钩子。

```
他抬手，敲了敲门。
```
```
电话那头说：你已经在里面了。
```
```
我按下录音键。然后我听见了自己的声音，在回答我。
```

**力度**：★★★★☆（戛然而止）
**风险**：较高。读者会觉得"没讲完"——适合做系列，不适合做独立作品。

---

## 二、怎么选（一张表）

| 你想达到 | 选 |
|---|---|
| 稳、能传播、评论区复述 | **1 增量式** |
| 想看两遍、评论区吵、后劲大 | **2 疑点式** ← 你说的这种 |
| 做系列、留钩子、快节奏 | **3 悬置式** |
| 拿不准 | **1**，然后从 1 的结尾再削一刀 → 变 2 |

> 从"增量式"到"疑点式"的削法：**保留那个物证，删掉所有解释和情绪总结**。

---

## 三、疑点式的写法公式

```
【日常场景】+【一个可验证的物证】+【它不符合前面任何一件事】
+ 【停。不解释。】
```

拆开看：

| 要素 | 反例（写坏） | 正例 |
|---|---|---|
| 物证要硬 | "我感觉有什么不对" | "搜索结果 0 条" |
| 只给一个 | "照片多了人，录音多了声音，门还自己开了" | 只给"搜索 0 条" |
| 不解释 | "也许我从来就没回来过" | 不写这句 |
| 不总结情绪 | "我崩溃了" | 不写 |
| 停在动作/物证 | "我陷入了深深的恐惧" | "门开了。" |

---

## 四、最容易被写坏的 5 种"假留白"（禁止）

1. ❌ **反问收尾**：「这到底是怎么回事？」——把读者当傻子的经典烂尾
2. ❌ **解释性留白**：「也许他只是……但也可能……」——留白不是让你列出可能性
3. ❌ **装神弄鬼**：「有东西在看着我」——没物证，是空话
4. ❌ **强行升华**：「原来人最怕的是自己」——这不是恐怖故事，是鸡汤
5. ❌ **多疑点堆叠**：一个故事给三个疑点，读者忙着推理，忘了害怕

## 五、和"换场景"的关系

三幕七拍的 **Ⅶ 反噬必须换场景**（野外→室内），这条不变。
**但"换场景之后"怎么收，现在有三种选择**：

```
拍Ⅶ = 换场景（必须）
     ├─ 收法1：日常场景里发现"多了一样东西"
     ├─ 收法2：日常场景里发现"一个说不通的物证/数据"
     └─ 收法3：日常场景里，一个动作/一句话，切断
```

> 换场景是**节的规则**，收法是**点的规则**。两者叠加，不是替代。

## 六、自检（写完结局必过）

- [ ] 我选的是三种收法里的哪一种？（能一句话说出来吗）
- [ ] 如果选疑点式：**是否只有一个疑点**？
- [ ] 这个疑点是不是**可验证的**（照片/记录/数字/物证），而不是"感觉"？
- [ ] 我有没有**多写一句解释**？（有→删。这是最高频的错）
- [ ] 有没有出现"这到底……""也许……""原来……"？（有→删）
- [ ] 把最后一句单独读：**它像不像一句废话**？像→重写
- [ ] 读者看完会不会想问"那到底为什么"？**会 → 成功；不会 → 你的疑点不够刺**

## 七、三个直接可用的疑点式结尾模板

```
模板 A · 数据不符
    「他回到出租屋。手机连上 WiFi 的瞬间，相册自动同步了
     三百二十七张照片——全是他失踪的那四天拍的。」

模板 B · 物证多出
    「他洗完澡出来，桌上放着一杯还热的茶。冰箱上贴着便条：
     '先喝口热的'——是他的字，可他刚搬进来，还没买过茶叶。」

模板 C · 记录矛盾
    「出院小结上写着：住院七天，体温记录十九次，
     全部是 27 度。医生签了字，没有备注。」
```
> 这三个都不用解释，疑点自己会发声。
