## 01_选题卡.md

```markdown
# 选题卡 · {选题}

- **用户原话**：{一句选题}
- **场域类型**：{地下/水下/垂直/人造废墟/自然异境/时间重复}
- **下沉方向**：{往下/往深处/往上/往内/往时间里}
- **怪诞源**：{神像/生物/人造物/时间重复/人体自我}
- **结尾场景**：{默认 医院病房；可换}
- **味道关键词**：探险 · 脑洞 · 怪诞 · 细思极恐
- **一句核心恐怖**：{读者最后怕的是什么}
- **结尾增量（具体到能画）**：{多出来的那样东西}
- **目标帧数**：{12–25}
- **目标模型**：{openai/gpt-image-2 / google/gemini-3.1-flash-image / 其他}
```

## 02_故事线.md

```markdown
# 故事线 · {选题}

## 一句话
> {用纪实外壳装一个不断下沉的异常空间；最后用 {结尾场景} 把恐怖收回日常。}

## 七拍骨架

| 拍 | 帧 | 这一拍发生什么 | 视觉钩子 |
|---|---|---|---|
| Ⅰ 现实锚点 | 1–3 | | |
| Ⅱ 门槛 | 4–5 | | |
| Ⅲ 第一层下沉（不可逆点：{动作}） | 6–10 | | |
| Ⅳ 第二层下沉 | 11–16 | | |
| Ⅴ 最深处（揭示） | 17–21 | | |
| Ⅵ 逃出 | 22–23 | | |
| Ⅶ 反噬 | 24–25 | | |

## 空间层级（每层比上一层更…）
1. {表层} →
2. {第二层，更…} →
3. {第三层，更…} →

## 结尾增量
- 媒介：{照片/视频/录音/报告}
- 增量：{具体}
- 与主角的关联：{强关联点}

## 五问自检
- [ ] 核心恐怖一句话？ - [ ] 增量能画？ - [ ] 不可逆点帧号？
- [ ] 层级升级在哪？ - [ ] 结尾换场景？
```

## README.md（交付说明）

```markdown
# {选题} · 探险脑洞图文

- 帧数：{N}｜画幅 9:16｜模型：{model}
- 核心恐怖：{一句}
- 结尾增量：{一句}

## 怎么跑
1. 先跑定价帧（第 {hero} 帧），`count=4` 挑图。标准见 06_验收清单.md
2. 定住后生成"定妆照"，之后所有帧 `images=[定妆照]` 锁人
3. 批量：见 `render_commands.txt`

## 字幕
- 中文一律后期叠（见 skill 的 references/09）
- 文案在 `prompts.json` 的 subtitle_zh 字段

## 已知取舍
- {如：某帧人物偏大，需后期处理 / 某帧需 inpaint}
```
