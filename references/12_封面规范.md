# 12 · 封面规范（封面 ≠ 内容图）

> 封面是**海报**，内容是**故事**。两套版式，别混用。
> 内容帧：一帧一句小字幕（见 `09_字幕与后期.md`）。封面帧：**大标题 + 副标题**，一眼看出这组讲什么。

---

> 版式参照图：`examples/`（本 skill 自己生成的成品）

## 一、两者的区别

| | 封面帧（id=00） | 内容帧（01…） |
|---|---|---|
| 作用 | 让人**点进来** | 让人**看下去** |
| 构图 | 主体压下方 2/3，**上方留安静暗区放标题** | 按七拍走，不一定留白 |
| 人物 | 极小（≤12%），作为尺度锚 | 按阶梯递减 |
| 文字 | **大标题（画面宽×0.105）+ 副标题（×0.042）** | 小字幕（×0.062），2–3 行 |
| 底框 | 圆角框包住标题块，alpha≈115 | 圆角框包住字幕块，alpha≈120 |
| 位置 | 画面上 1/3（y≈0.33） | 画面下方（y≈0.80） |

---

## 二、封面帧的提示词写法

在 `scenes.json` 加一帧：

```json
{
  "id": "00",
  "beat": "封面",
  "compo_variant": "cover",
  "style_variant": "STYLE",
  "material_variant": "default",
  "light": "L2",
  "lens": "up",
  "fig_scale": 12,
  "scene_en": "Scene: ...（主体 + 环境 + 一条引导线）",
  "fig_anchor_en": "He is a small dark mark, no taller than ..., easy to miss. He stands off centre in the lower third, his head below the lower quarter line.",
  "subtitle_zh": ""
}
```

`compo_variant: "cover"` 会自动套上专用构图块：**主体占下 2/3、上方留低细节暗区、人物极小、单焦点、强明暗分离**。

> 封面帧的 `subtitle_zh` 留空——封面文字不走小字幕，走 `make_cover.py`。

## 三、标题文案怎么写

- **主标题**：选题名，**4–8 字**最稳（「深山禁寺」「雪山的信号」）
  - 太长会换行、变小、失去冲击力
- **副标题**：一句话钩子，**12–22 字**，可省略
  - 好的副标题 = 悬念 + 具体细节：「父亲失踪三年后，我在雪山里收到了他的信号」
  - 避免："一个关于雪山的故事"（空）
- 写进 `meta.cover`：
```json
"meta": { "cover": { "title": "雪山的信号", "subtitle": "父亲失踪三年后，我在雪山里收到了他的信号" } }
```

## 四、生成命令

```bash
python scripts/make_cover.py <项目目录>
# 可调：--title-ratio 0.12   --y 0.28   --title "临时标题"   --image out/00_cover.png
```

输出 `out/subtitled/00_封面.png`。

**字体**：与字幕共用一套（默认 Noto Sans SC Black；`fonts/` 放得意黑会优先用）。标题用 Black，副标题用 Medium，形成层级。

---

## 五、封面自检（5 条）

- [ ] 标题一眼能读完（不超过 2 行，字号够大）
- [ ] 标题压在上方暗区，不糊在亮部/主体脸上
- [ ] 主体够震撼，人物小到能体现"巨大"
- [ ] 底框只包住文字，不是整幅长条
- [ ] 缩小到手机列表尺寸（约 200px 宽）时，标题仍然可读

> 最后一条最关键：**封面要在小图状态下就能看清标题**。做完了把图缩小看一眼。
