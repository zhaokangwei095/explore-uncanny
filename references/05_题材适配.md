# 05 · 题材适配（换选题时只改这几处）

> 骨架不动，改的是:①下沉方向 ②异常载体 ③R2/R6 的"物" ④STYLE/MATERIAL 的色调与材质词 ⑤服化。
> 每种题材给：下沉方向 / 异常载体 / 必换的词 / 一句示范选题。

---

## A. 地下类（矿井、地宫、溶洞、防空洞、地下城）

- 下沉方向：往下
- 异常载体：神像 / 石刻 / 骨骸 / 会生长的岩层
- 必换词：MATERIAL 用湿岩苔藓（默认即可）；LIGHT 主用 L2/L3
- 示范：「废弃矿道尽头的祠堂」——矿车轨道通往一座地下的、供着"矿工神"的祠

---

## B. 水下类（沉船、钻井平台、海底遗迹、水库底）

- 下沉方向：往深处
- 异常载体：沉船里的人形藤壶丛 / 平台底部的巨脸 / 会发光的腔体
- 必换词：
  - STYLE 里 `wet stone` → `wet steel and silt`
  - MATERIAL → `barnacle crust, silt film, suspended particles drifting in the beam, rust bleeding from steel`
  - LIGHT 用 L3（头灯），必须有 `suspended particles in the beam`
  - TAIL 不变
- 服化：潜水服 + 气瓶 + 头灯
- 示范：「深海钻井平台的第七层甲板以下」——平台钢腿在海底不是插进淤泥，而是踩进一只朝上的巨掌

---

## C. 垂直类（巨塔、竖井、摩天楼、天梯、电梯井）

- 下沉方向：**往上**（反向的"下沉"，越往上越怪）
- 异常载体：每一层是一个人 / 塔顶不是天空 / 楼梯接回自己
- 必换词：
  - COMPO 仍可 C1 仰拍（`top lost above the frame` 天然合适）
  - 加 `the stairwell repeats upward until it merges into darkness`
- 示范：「一栋有 99 层、但电梯只按到 47 层的旧办公楼」

---

## D. 人造废墟类（医院、工厂、实验站、学校、商场）

- 下沉方向：往下（管线/地下层）或往内（核心实验区）
- 异常载体：实验记录 / 培养舱 / 病床编号 / 广播
- 必换词：
  - MATERIAL → `oil stains, settled dust, condensation on cold metal, peeling paint, yellowed paper`
  - LIGHT 常用 L2 + 手电 L3
- 示范：「停用十年的气象站，所有观测记录都是关于山下某个人的」

---

## E. 自然异境类（峡谷、冰川、密林、沙漠、天坑）

- 下沉方向：往地理深处（天坑/冰缝/树根下）
- 异常载体：地形本身是一张脸 / 冰川里有撑起冰层的手 / 树的根系是血管
- 必换词：
  - STYLE_DAY 用得更多（外景多）
  - 冰川：MATERIAL → `blue ice, wind crust, frost ferns, meltwater sheen`
- 示范：「天山天坑，坑底的森林排列成一个字的形状」

---

## F. 时间/重复类（同一空间不同时代、循环、昨日重现）

- 下沉方向：往时间里（越走越"旧"或越"新"）
- 异常载体：同一张照片里出现不同年代的人 / 同一条走廊同一段对话重复
- 必换词：
  - R4 不可能几何是主规则
  - LIGHT 固定（时间静止感），用 L2
- 示范：「一条省道，每隔 7 公里回到同一个加油站，但店员一次比一次老」

---

## 通用换词清单（照着改就不会跑偏）

| 原（深山禁寺） | 换题材时要改的地方 |
|---|---|
| `wet stone / carved stone / lichen` | 按题材换材质（钢/冰/土/木/骨） |
| `Buddhist / statue / naga / temple` | 换成该题材的神圣/异形符号 |
| `hiking boots / backpack / softshell` | 换成该题材的职业装备 |
| `bamboo grove` | 换成该题材的入口环境 |
| `hospital ward` | 换成该题材的"日常收尾场景"（卧室/办公室/车里） |
| 结尾"小雕像" | 换成该题材的"小增量"（见 `01_方法论骨架.md` 的增量公式） |

---

## 千万别做的"换皮"

- ❌ 只把"佛"换成"神"、其余照抄 → 一眼是同一个模子，读者会出戏
- ❌ 换题材但保留"寺庙/佛像"的构图语言（对称巨脸、香炉）→ 串味
- ❌ 为了"不一样"破坏骨架（不要下沉、不要背影、结局是怪物）→ 就不是这个风格了

**正确做法**：骨架（七拍/下沉/巨物/背影/增量结局）100% 保留，**内容 100% 换新**。
